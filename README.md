# 📚 Smart Study Planner

A simple command-line study planner built with Python to help organize and manage study tasks.

## ✨ Features

- ➕ Add new tasks
- 📋 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Automatically save tasks using JSON
- 🔄 Automatically load saved tasks when the program starts
- ✔️ Basic input validation

## 🛠️ Technologies Used

- Python 3
- JSON
- Git & GitHub

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder.
3. Run:

```bash
python main.py
```
